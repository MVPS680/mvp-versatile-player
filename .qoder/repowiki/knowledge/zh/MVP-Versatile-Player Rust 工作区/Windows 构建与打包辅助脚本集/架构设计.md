脚本以 ffmpeg-env.ps1 作为唯一共享模块，集中定义机器本地的 FFmpeg 版本常量、默认路径、配置解析（读取 .cargo/config.toml）以及 FFmpeg 开发包与 libclang 的发现逻辑；其余脚本通过 dot-source 引入该文件，形成单向依赖：
- setup-ffmpeg.ps1：一次性安装/解压 FFmpeg 9.0 shared 开发包并探测 libclang，生成 .cargo/config.toml 中的 FFMPEG_DIR、LIBCLANG_PATH、BINDGEN_EXTRA_CLANG_ARGS 条目。
- dev.ps1：在运行任意 cargo run/test 前将 FFmpeg bin 加入 PATH 并导出 FFMPEG_DIR，同时自动触发 setup-ffmpeg.ps1 -NoDownload 完成首次配置。
- package.ps1：调用 dev.ps1 构建 release 二进制，并将 exe 与 FFmpeg 全部 DLL、README、LICENSE、LICENSE-FFmpeg 复制到 dist/MVP-Versatile-Player 形成自包含分发目录。
- make-icon.ps1：使用 System.Drawing 动态绘制多尺寸圆角紫色 Logo 并手工写入 ICO 文件头，避免提交二进制资源。
- make-testdata.ps1：调用外部 ffmpeg.exe 生成 tiny.mp4/mp3/png/gif/ts 等极小测试素材供端到端播放测试使用。
所有脚本均不修改仓库代码，仅读写本机路径与 .cargo/config.toml（已被 gitignore），保证跨机器可重复执行。
