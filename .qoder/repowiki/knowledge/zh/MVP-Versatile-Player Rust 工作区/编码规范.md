- 所有 crate 共用 workspace 级别的版本号、edition、rust-version 与 license，避免各子 crate 重复声明
- 跨 crate 共享的第三方依赖统一在 `[workspace.dependencies]` 中声明并由子 crate 引用，禁止在子 crate 中各自指定版本
- 错误处理统一采用 anyhow/thiserror，日志通过 log + env_logger 输出
- release 构建统一启用 fat LTO、单 codegen-unit 与 strip=symbols，dev 构建保留增量编译并对核心 crate 提升优化级别
