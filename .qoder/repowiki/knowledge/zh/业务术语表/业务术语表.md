### MVP Update Manager
- 定义：项目自研的外置更新管理服务，部署于 `https://updateman.mvpclub.cc/`，提供公开 API 供客户端查询最新版本、下载链接、SHA-256 校验值及强制更新标志。每个产品通过唯一标识（如 `MVP-Versatile-Player`，数字 ID 为 7）区分。
- 别名：更新管理系统、updateman.mvpclub.cc、更新服务

### 外置更新器
- 定义：独立的小体积可执行程序 `mvp-updater.exe`，由主程序触发，负责下载新版 zip、比对变更、原子替换安装目录文件并在失败时回滚，最后重启主程序。它与主程序解耦，不依赖 egui/FFmpeg，避免引入额外体积。
- 别名：updater、更新器

### install.json
- 定义：更新器在安装目录下维护的缓存文件，记录上次成功安装的 zip 中央目录清单（文件路径→哈希），用于增量比对，只替换变化的文件而非每次全量覆盖。
- 别名：安装缓存

### check_updates_on_startup
- 定义：用户偏好设置项（持久化在 `settings.json`），控制程序启动后是否自动静默检查更新。默认开启，启动约 2 秒后触发，发现新版本弹出更新对话框。
- 别名：启动检查更新、自动检查更新

### Overlay::Update
- 定义：主程序 UI 层用于展示更新状态的覆盖层（弹窗），包含进度条、下载状态、失败重试和「打开下载页面」等动作；强制更新模式下不可通过 Esc 关闭。
- 别名：更新弹窗、更新覆盖层
