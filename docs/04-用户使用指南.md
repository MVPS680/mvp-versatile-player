# 用户使用指南

> 面向使用者，不需要任何技术背景。装完、打开、看片，全程不需要管理员权限。
> 演示前可以把这份文档发给评委或试用的同学。

---

## 1. 安装与第一次启动

本播放器是**免安装的绿色软件**：

1. 把整个程序目录拷贝到任意位置（桌面、D 盘、U 盘都可以）。
2. 双击目录里的主程序即可运行，**不需要安装、不需要管理员权限**。
3. 想让双击文件时默认用本播放器打开 → 打开**设置 → 系统集成 → 注册文件关联**。
4. 想撤销 → 同一位置点**取消关联**，不会留下任何残留，也不会影响其他播放器的关联设置。

> 小提示：程序会把运行日志写在你的用户目录下（超过约 2 MB 自动轮转），
> 菜单「帮助 → 查看运行日志」可以直接打开。出问题时把日志末尾几行发出来，便于定位。

## 2. 打开媒体的四种方式

| 方式 | 操作 |
|---|---|
| 双击文件 | 注册关联后，双击视频/音频/图片即可打开并**直接开始播放** |
| 右键 → 打开方式 | 在资源管理器里右键素材，选择本播放器 |
| 拖入窗口 | 把一个文件、一批文件或者一个**文件夹**拖进窗口 |
| 菜单 / 快捷键 | `Ctrl+O` 打开文件、`Ctrl+Shift+O` 打开文件夹、`Ctrl+U` 打开网络地址 |

补充说明：

- 拖入**文件夹**会递归扫描（最多 4 层），并按自然顺序排序 —— 「第2集」会排在「第10集」前面。
- 拖入播放列表文件（`.m3u` / `.pls` / `.xspf`）会自动展开成其中的条目。
- 双击文件带来的素材被视为"明确的播放指令"，会立刻播放；如果你希望这次打开后先停在第一帧，
  启动时加参数 `--no-autoplay`（只影响这一次）。

## 3. 界面导览

```
┌──────────────────────────────────────────────────────────┐
│ 文件  播放  视频  音频  字幕  工具  帮助                     │  菜单栏
├───────────────────────────────────┬──────────────────────┤
│                                   │  播放列表 / 轨道 /   │
│              画面区域              │  章节 / 媒体信息     │  侧边栏
│                                   │                      │
├───────────────────────────────────┴──────────────────────┤
│ 00:12:04  ─────────●───────────  02:31:55   ⏮ ⏯ ⏭  🔊 ▣  │  控制栏
└──────────────────────────────────────────────────────────┘
```

- **画面区域**：视频画面或图片。鼠标停在画面上滚轮可以调音量；拖动画面可以平移图片。
- **侧边栏**：四个标签页 —— 播放列表、轨道（音轨/字幕轨）、章节、媒体信息（分辨率、编码、
  动态范围、杜比视界信息等）。按 `T` 或 `Ctrl+L` 显示/隐藏。
- **控制栏**：进度条、播放控制、音量、循环模式。全屏时会自动隐藏，鼠标一动就回来。
- **性能统计**（在菜单里开启）：解码帧数、丢帧、队列深度、音频欠载、启动耗时等，
  想知道"为什么有点卡"时可以看这里。

## 5. 字幕

- **自动加载**：打开视频时，如果同目录有同名（或带语言后缀）的字幕文件，会**自动加载**。
  语言后缀优先匹配中文（`.zh` / `.chs` / `.cht` 等）。
- **内嵌还是外部**：默认「外部字幕优先」；不想用时，在设置里改成优先使用内嵌字幕，
  只有在没有内嵌字幕时才回退到外部文件。
- **编码**：程序会自动识别 UTF-8 / UTF-16 / GBK / Big5 / Shift_JIS / Windows-1252，
  中文外挂字幕通常不需要任何额外操作。
- **显示调整**：字号、颜色、衬底、距底部的距离都可调。
- **对不上口型**：在「字幕」菜单里微调字幕延迟（±10 秒）。
- **手动挂载**：按 `G`，或在「字幕」菜单里选择字幕文件。
- **图形字幕（PGS / VobSub）**：这类字幕是图片而不是文字，本播放器无法显示，
  轨道页会明确告诉你原因。

---

## 6. 图片

- 支持 PNG / JPEG / GIF / WebP / BMP / TIFF / ICO / TGA / QOI / PNM / EXR 等常见格式。
- 动画 GIF / WebP / APNG 会逐帧播放。
- 操作：缩放、平移、旋转、水平/垂直翻转、适应窗口、100% 原图；手机上拍的照片会**按方向自动转正**。
- 幻灯片：把整个文件夹拖进窗口，图片会按顺序播放。
- 超大图片（几千万像素）会自动缩小到显卡能承受的尺寸，不会把显存吃光。

---

## 7. 网络播放

「文件 → 打开网络地址」（`Ctrl+U`），支持 `http` / `https` / `rtsp` / `rtmp` / `udp` / `rtp` / `srt` / HLS。
直接把网址粘进去即可。

> 注意：`.m3u8` 既可能是用户自己写的播放列表，也可能是网络直播清单，
> 程序会读取内容自动区分，一般不需要你操心。

## 8. 值得改的几个设置

| 设置项 | 什么时候改 |
|---|---|
| 系统集成 → 注册文件关联 | 希望双击素材就用它打开 |
| 字幕 → 外部字幕优先 / 内嵌字幕优先 | 你更喜欢用文件自带的字幕 |
| 视频 → HDR 色调映射 | HDR 片源看着发灰时保持开启；觉得画面太亮或追求原始效果时关闭 |
| 播放 → 记忆上次播放位置 | 追剧、看网课必备（默认开启） |
| 界面 → 侧边栏 / 性能统计 | 想要更大的画面，或想看看播放状态 |
| 快捷键帮助（`F1`） | 忘了某个键做什么 |

## 9. 常见问题

**Q：双击文件没有用本播放器打开？**
A：进入**设置 → 系统集成 → 注册文件关联**。注册只影响你自己的账户，不需要管理员权限。

**Q：字幕是一堆方块或乱码？**
A：正常情况下程序会自动识别编码。若仍然乱码，用「字幕 → 加载字幕文件」手动指定一次；
如果还是不行，把该字幕文件的来源发给我们（个别字幕文件本身编码异常）。

**Q：没有声音？**
A：① 检查是否静音（`M`）、音量是否为 0；② 检查系统默认音频设备是否正确；
③ 侧边栏「轨道」页确认音轨没有选错；④ 如果用的是启动参数 `--no-audio`，这次启动不会有声音。

**Q：HDR 电影看起来发灰 / 太亮？**
A：到**设置 → 视频 → HDR 色调映射**里把它打开或关闭对比一次。
另请注意：杜比视界影片我们播放的是兼容基底层，效果等同于 HDR10，不会更亮更艳。

**Q：拖进度条之后画面黑了一下？**
A：某些格式（例如蓝光式的传输流）只能跳到最近的"关键帧"，所以落点可能与点击位置略有差异，
这是格式本身的限制；但画面**不会**停在黑屏，也不会往回跳到比你点的位置更早的地方。

**Q：打开 ISO 镜像提示无法播放？**
A：ISO 是"装了文件的容器"，需要先用系统把它**装载**成虚拟光驱，再打开里面的视频文件。

**Q：某些字幕一直显示不出来？**
A：检查侧边栏「轨道」页 —— 如果提示是图形字幕（PGS / VobSub），那是图片形式的字幕，
本播放器无法显示（需要文字识别）。

**Q：播放列表顺序不对？**
A：现在的排序已按自然顺序处理中文序号。如果你的文件名格式比较特殊（例如"第01集 上"），
可以用列表里的上移/下移按钮手动调整。

**Q：想换回别的播放器怎么办？**
A：设置 → 系统集成 → **取消关联**，然后重新注册你想要的播放器即可。取消关联不会留下任何残留。

**Q：程序关了窗口还在后台？**
A：程序是单实例设计：再次双击文件会把文件送到已经打开的窗口并前置它。
如果确实想完全退出，请用菜单里的退出（或关闭窗口），不要只最小化。

## 10. 卸载与清理

1. 打开**设置 → 系统集成 → 取消关联**（这一步会把注册表里相关内容全部清除）。
2. 关闭程序，删除整个程序目录。
3. 如果想连个人设置一起清掉，删除用户目录下的 `MVP-Versatile-Player` 文件夹（含设置与日志）。

没有安装程序、没有后台服务、没有计划任务、没有开机自启项。
