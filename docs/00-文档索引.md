# 文档索引 · MVP-Versatile-Player（答辩与 PPT 素材）

> 本目录下的文档**全部面向非技术读者**（评审老师、答辩评委、团队做 PPT 的同学）。
> 里面不出现代码、模块名和技术行话；凡是技术概念，都换成"现象 + 结论 + 效果"的说法。

**一句话介绍**：一款为 Windows 打造的"放下了就不用管"的多功能音视频与图片播放器 ——
常见格式都能放、中文外挂字幕不乱码、图片也能看、和资源管理器是一家人、开得快关得也快。

## 全队统一口径（重要）

### 数字口径

答辩里出现的每一个数字都要说清"怎么测的、在什么条件下"。本文档中的实测数据来自开发机
（Windows 桌面版，具体配置见 `03` 数据卡），口径都在括号里注明了。**不要凭印象改数字，也不要
把调试构建的数字说成发布构建的数字。**

### 可以放心讲的

- 直接集成 FFmpeg 内核（不是调用外部 `ffmpeg.exe` 子进程）、硬件解码（不可用时自动回退软件解码）
- HDR10 / HLG 识别与色调映射、杜比视界配置信息识别
- 内嵌与外部字幕、自动识别 GBK 等六种编码
- 图片查看（含动画图）、幻灯片、EXIF 方向自动旋转
- 文件关联写入当前用户区、**不需要管理员权限**、不抢占别人已占用的关联
- 单实例（再次双击文件加入到已打开的窗口）
- 变速播放（0.25x–4.0x，保持音高）、音量 0–200% 带软限幅
- 网络串流、断点续播、截图、A–B 循环
- 200 余项自动化测试，其中包含端到端真实解码播放测试

### ⚠️ 不要写进 PPT 的内容（会被问倒）

| 不要写 | 真实情况 |
|---|---|
| 支持 JXL / AVIF 图片 | 这两个解码器**没有编进程序**，实际打不开。只讲 PNG / JPEG / GIF / WebP / BMP / TIFF / ICO / TGA / QOI / PNM / EXR 等 |
| 支持 PGS / VobSub 图形字幕 | 不支持（它们是位图字幕，需要文字识别）。遇到这类轨道程序会**明确提示**，这是主动设计 |
| 可切换视频轨道 | 不支持。多条视频流时只解码第一条，轨道页会写出来 |
| 完整支持杜比视界 | 只播放**兼容基底层**（相当于 HDR10 效果），增强层不叠加；Profile 5 无法正确还原，程序会明确提示 |
| HDR 色调映射是"硬件/显卡加速"的 | 目前是 CPU 上的近似实现，性能有限（发布版本快数倍），未来计划改用显卡着色器 |
| 已经支持拖放排序播放列表 | 目前用行内上移/下移箭头实现排序，未做鼠标拖放 |
| 100% 还原所有杜比视界片源 | 见上一条，明确告知用户比假装正常更重要 —— **这本身就是我们的亮点** |
